# Sistema de Gestão e Análise de Vendas

Aplicação desenvolvida em Python para gerenciar produtos, clientes e vendas, armazenar informações em SQLite e consultar o histórico de vendas.

> Projeto de portfólio e aprendizado. Desenvolvido para praticar programação Python, operações com banco de dados e organização de aplicações.

## Funcionalidades

- Cadastrar e gerenciar produtos.
- Cadastrar e gerenciar clientes.
- Registrar vendas.
- Consultar o histórico de vendas.
- Armazenar informações em banco de dados SQLite local.

## Tecnologias

- Python
- SQLite (`sqlite3`)
- SQL

## Próximas melhorias planejadas

- Criar relatórios com indicadores de vendas.
- Adicionar filtros por período e produto.
- Implementar gráficos para análise dos resultados.
- Exportar relatórios para CSV.
- Adicionar novas validações e testes.

## Aprendizados demonstrados

Este projeto permite praticar lógica de programação, organização de módulos, funções, operações CRUD, manipulação de dados, integração com banco de dados relacional, consultas SQL, testes e versionamento com Git.
